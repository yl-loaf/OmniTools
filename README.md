# OmniTools 🛠️✨

OmniTools is an enterprise-grade, blazing-fast web application featuring **55+ production-grade daily life, developer, design, and productivity utilities**, built with React, TypeScript, Tailwind CSS, and Firebase.

---

## 🌟 Core Features & Utilities Suite

### 1. **Daily Life & Productivity Suites**
- **Health, Fitness & Tips**: Tip splitter, BMI calculator, TDEE daily calorie target, hydration tracker, and sleep cycle calculator.
- **Finance, Recipe & Savings**: Kitchen ingredient scaler, road trip fuel cost estimator, percentage markup calculator, and compound growth retirement planner.
- **Productivity & Meeting Planner**: World timezone meeting planner, ETA travel calculator, daily Eisenhower task priority matrix, and reading time estimator.
- **Home, Travel & Packing**: Parking meter expiry countdown, box & packing volume calculator, weather heat index comfort calculator, and canvas social media matrix.
- **Quick Utilities**: GPA calculator, stacked flash sale discount calculator, egg & tea steeping timers, and daily inspiration quote generator.
- **Event Countdown Timer**: Real-time countdown clock in `mm:dd:hh:mm:ss` format.
- **High-Precision Percentage Timer**: Timer with a dynamic decimal percentage progress bar ticking 10+ times per second.

### 2. **Developer & Code Lab**
- **Markdown Studio**: GFM live previewer, table generator, and HTML export.
- **JSON & TypeScript Studio**: Format, validate, tree view, and TypeScript interface generator.
- **SQL Query Beautifier**: Format ANSI, MySQL, and Postgres SQL statements.
- **Text & Code Diff Inspector**: Side-by-side line & character diff comparison.
- **Regex Lab**: Pattern tester, string replacement, and regex presets.
- **JWT Debugger**: Decode headers, payload claims, and expiration timestamps.
- **cURL & API Code Builder**: Convert cURL to Fetch, Python requests, and Axios.
- **Cron Expression Scheduler**: 5-field visual cron builder and plain English translator.
- **Linux chmod Calculator**: Numeric octal (755/644) and symbolic permission solver.
- **KeyCode & Event Tester**: Inspect JS key codes, events, and modifiers.

### 3. **Design & Media Utilities**
- **Color Harmony & Contrast Studio**: Color harmonies, WCAG 2.1 contrast checker, and gradients.
- **CSS Glass & Shadow Studio**: Glassmorphism, multi-shadows, and clip-path generator.
- **Aspect Ratio & DPI Solver**: Resolution solver, print DPI, and video dimensions.
- **SEO & Meta Card Studio**: OpenGraph, Twitter card, and search preview generator.
- **SVG Vector Cleaner**: Minify SVG paths and generate Data URIs.
- **QR Code & Barcode Studio**: Scannable URLs, Wi-Fi, vCards, and Code 128 barcodes.

### 4. **Data, Security & Finance**
- **Base64 & Hash Crypto Suite**: Base64 encoding/decoding and SHA-256 / SHA-512 hashes.
- **Password & UUID Generator**: NIST-compliant passwords, passphrases, and UUID v4.
- **CSV Data Grid & JSON Studio**: Spreadsheet viewer, search, and markdown table exporter.
- **HTML Entity Encoder**: Escape special symbols and unicode codes.
- **HTTP Status Code Lookup**: REST API 2xx, 3xx, 4xx, and 5xx guide.
- **Scientific Calculator & Finance Studio**: Trig functions, exponents, mortgage amortization, and loan calculators.

## 🏆 Community, Gamification & Admin Workflow

- **Community Request Hub**: Propose new tool ideas, vote on features, and feed prompts into AI.
- **Leaderboard & Tiered Badges**: Earn **Contribution Points (CP)** through daily check-ins, feature proposals (+2 CP), and bug report resolutions (+3 CP). Unlock tiers from Bronze to Master Architect and buy streak freezes.
- **Bug Report & Fix Workflow**: Users can report broken features on any tool. Admins can review bug reports, type fix notes, resolve them, and automatically award **+3 CP** to the reporter.
- **Executive Admin Portal**: Features **Batch Copy (Top 1, 2, 5, 10, 20, 25)** for both feature requests and bug reports, shipping version assignment, status updates, and 7-day automated Firebase storage retention purging.

## 🚀 Tech Stack

- **Framework**: React 18+ with TypeScript & Vite
- **Styling**: Tailwind CSS (v4)
- **Icons**: Lucide React
- **Backend & Auth**: Firebase Firestore & Authentication (with local storage fallback)
- **Deployment**: Node.js / Express Server Integration
